## 二、主要問題與建議

### 1. 「其他」占 51%（355 筆）—— 最該改善 🔴
分類過粗，抽籤時幾乎無法用類型篩選。
- **根因**：本次新店家因 Gemini API key 失效（見下），改用本地啟發式分類，大量落入「其他」；舊資料也有不少未細分。
- **建議**：待 Gemini key 修復後**重跑分類**，並把現行 7 類細化為可用子類：
  `小吃／麵食／飯食／早餐／咖啡甜點飲品／火鍋／燒烤串燒／素食／異國料理／酒吧居酒屋`。

### 2. 新增「地區」維度 🟡
半數以上（375 筆）距家 >50km，多為旅遊景點；真正日常可用的是 ≤5km 的 211 筆。
- **建議**：加一欄 `地區`＝`住家圈(≤5km)／新竹生活圈(≤15km)／北部／中部／南部／國外`，抽「今天吃哪」時先濾住家圈，旅遊清單另開。

### 3. 合併重複來源清單 🟡
`民眾台八線`(28) 與 `民眾台8線`(8) 是同一份、兩種寫法 → 應合併為一。

### 4. 由來源清單推導「場合」標籤 🟢
來源已隱含用餐情境，可自動帶入 `場合`：
`常用早餐→早餐`、`下午茶→下午茶`、`常用晚餐→晚餐`、`消夜→宵夜`。

### 5. 價位分級已合理 🟢
$$ 與 $ 為主，符合日常外食；維持現行四級即可（未知 17 筆待補）。
