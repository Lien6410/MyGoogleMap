# 雲端回寫指南：把清理結果套回 Google Maps

> 產生日期：2026-06-21

## 一、先講結論：能與不能

| 想做的事 | 可行性 |
|---------|--------|
| 程式自動**覆蓋/刪除**你 Google 帳號的「已儲存/想去/星號」清單 | ❌ **不可能** — Google 沒有開放寫入個人珍藏清單的 API |
| 把整理好的清單做成**可匯入的自訂地圖** | ⚠️ 可行，但那是 **Google My Maps**（自訂地圖），非原生珍藏清單 |
| 從珍藏清單**移除已歇業店家** | ⚠️ 只能**手動**逐筆移除（見下方清單）|

**為什麼不能自動覆蓋？** Google Maps Platform 只提供『讀取地點資訊』的 API，**沒有**任何 API 能新增/刪除/修改使用者個人的珍藏清單（Saved/Want to go/Starred）。瀏覽器自動化（Playwright 自動點擊）違反服務條款、極脆弱、需登入，不建議。

## 二、務實的三條路

### 路徑 A（推薦）：手動清掉已歇業店家
整理結果中確認永久歇業的 **17 筆**列在第三節。逐筆點連結 → 在 Google Maps「已儲存」圖示取消儲存即可。數量不多，5–10 分鐘可完成。

### 路徑 B：用 Google My Maps 建立分類地圖
1. 開啟 [Google My Maps](https://www.google.com/mymaps) → 建立新地圖。
2. 圖層「匯入」→ 上傳 `data/output/MyGoogleMap_Stores_active.csv`。
3. 選經緯度或地址欄位定位、選「店名」當標題、用「餐飲類型」分顏色。
（注意：單一圖層上限 2,000 筆；這是**自訂地圖**，與手機上的珍藏清單是不同功能。）

### 路徑 C：維持現狀
珍藏清單留在雲端不動，整理/抽籤都用本地 `data/output/`（lottery.html）即可。雲端只當原始輸入來源（每次重新 Takeout 匯出）。
